# DHA: A Discrepancy-Driven Hierarchical Approach for Synthetic Image Attribution


This repository contains the official implementation of **“DHA: A Discrepancy-Driven Hierarchical Approach for Synthetic Image Attribution.”** The paper has been accepted for publication in *IEEE Transactions on Multimedia (TMM) 🎉 🎉 🎉*.

The source code, complete pretrained model, and evaluation configuration used in this release are publicly available. The evaluation scripts report numerical metrics and save results as JSON files.
